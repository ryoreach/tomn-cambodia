# TOMN (តំណ)

**Connecting People. Simplifying Services.**

TOMN is a bilingual public information and service navigation platform designed to help Cambodian citizens find verified public-service information, understand procedures, prepare required documents, and locate official service channels.

## Project Objectives

- Make public-service information easier to discover.
- Provide clear Khmer and English service guides.
- Help citizens prepare required documents using checklists.
- Connect citizens with verified public offices and official channels.
- Provide an AI assistant that answers using approved sources.

## Technology Stack

| Component | Technology |
|---|---|
| Frontend | React, TypeScript, Tailwind CSS |
| Backend | Laravel REST API |
| Database | PostgreSQL |
| AI Service | Python, FastAPI |
| Maps | OpenStreetMap |
| Version Control | Git, GitHub |

## Project Structure

- `frontend/` — Web application
- `backend/` — Laravel API
- `ai-service/` — AI information assistant
- `database/` — Database documentation and scripts
- `docs/` — Project documentation
- `assets/` — Brand assets
- `tests/` — Testing resources

## Project Scope

TOMN is an independent public information platform. It is not a government authority and does not replace official government services.
